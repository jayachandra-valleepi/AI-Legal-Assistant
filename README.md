## ⚖️ AI Legal Assistant

AI-powered Legal Assistant using **RAG (Retrieval-Augmented Generation)** with LangChain, OpenAI, and Pinecone.

Users can upload legal documents and ask questions in natural language to get intelligent answers.

---

## 🚀 Features

- 📄 Legal PDF document analysis
- 🤖 AI chatbot for legal Q&A
- 🔍 RAG-based document retrieval
- 🧠 OpenAI embeddings
- ⚡ Fast semantic search with Pinecone
- 🌐 Flask web application

---

## 🛠️ Tech Stack

- Python
- Flask
- LangChain
- OpenAI
- Pinecone
- HTML & CSS
